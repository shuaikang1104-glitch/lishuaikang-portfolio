# Portfolio Website Direction

## Core Style
Apple × Arc × Nothing × Kirschberg

## Website Goal
Create a cinematic digital portfolio experience.

Not a traditional portfolio website.

## Visual Keywords
- Black Space
- Cinematic
- Spatial
- Digital Glow
- Controlled Minimalism
- Future Interface
- Motion
- Typography

## Navigation
- Floating capsule navigation
- VisionOS feeling
- Blur glass layer
- Center aligned navigation
- Minimal labels

## Hero
- Massive typography
- Huge empty space
- Slow motion
- Subtle glow
- Black background

## Works
- Fullscreen project sections
- No small cards
- Each project like a movie chapter
- Large immersive visuals

## Motion
- Framer Motion
- Slow easing
- Blur transitions
- Scroll-based movement
- Soft hover glow

## Avoid
- Traditional portfolio layout
- Behance style grid
- Small UI cards
- Over-designed WebGL effects
- E-commerce feeling
